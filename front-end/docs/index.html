Comment jouer ?

Codejoueur est une course de programmation multijoueur. Chaque joueur résout le même défi JavaScript avant la fin du chrono.

1. Créer ou rejoindre une salle

  1. Choisis un pseudo de 15 caractères maximum.
  2. Clique sur Créer une salle, puis partage le code à tes amis.
  3. Les autres joueurs saisissent ce code et cliquent sur Rejoindre.
  4. L'hôte lance la partie quand tout le monde est prêt.

2. Résoudre un défi

Lis l'énoncé, écris ta fonction dans l'éditeur puis soumets-la. Le serveur vérifie automatiquement la réponse avec plusieurs tests. Une manche dure trois minutes.

3. Règles du jeu

  • Sois fair-play : ne tente pas de perturber les autres joueurs.
  • Chaque joueur doit utiliser son propre pseudo et sa propre solution.
  • Un joueur qui n'a pas validé sa solution à la fin du chrono est éliminé.
  • Les pseudos, messages et codes ne doivent contenir aucun contenu illégal, haineux ou offensant.
  • Le résultat des tests est définitif pour la manche en cours.

Développer en local

cd backend
npm install
npm start

# servir le front-end
cd front-end
python -m http.server 8000

Le client utilise actuellement le backend de démonstration hébergé sur Render. Pour du développement local, modifie l'URL Socket.IO dans front-end/index.html.
