INFORMATION

Politique de confidentialité

Version : 17 septembre 2026. Cette page décrit le fonctionnement actuel de la version de démonstration de Codejoueur.

Données utilisées

Pour participer à une partie, Codejoueur reçoit ton pseudo, le code de la salle et les solutions envoyées pendant la manche. Le serveur utilise aussi l'identifiant technique temporaire fourni par Socket.IO pour associer un joueur à sa connexion.

Pourquoi ces données ?

Elles sont nécessaires pour créer les salles, synchroniser les joueurs en temps réel, vérifier les solutions et afficher les résultats.

Conservation

Les parties sont stockées en mémoire sur le serveur de démonstration. Les informations peuvent disparaître lors d'un redémarrage du serveur. Aucun compte permanent ni profil public n'est actuellement créé.

Services tiers

Le front-end utilise Socket.IO depuis un CDN et communique avec un backend hébergé sur Render. Le site de démonstration est hébergé sur Vercel. Ces services peuvent traiter des données techniques selon leurs propres politiques.

Ce que tu ne dois pas envoyer

N'envoie jamais de mot de passe, d'information personnelle, de secret, de clé API ou de code confidentiel dans un pseudo ou une solution.

Contact

Pour une question relative aux données, ouvre une issue sur le dépôt GitHub.
