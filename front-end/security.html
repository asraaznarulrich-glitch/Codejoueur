SÉCURITÉ & FAIR-PLAY

Règles de sécurité

Important : Codejoueur est une démonstration. N'y soumets aucun code ou contenu sensible.

Règles pour les joueurs

  • N'utilise pas le jeu pour envoyer du contenu malveillant, haineux, illégal ou harcelant.
  • Ne tente pas de saturer le serveur, de deviner les salles en boucle ou de perturber une partie.
  • N'envoie pas de secrets, de mots de passe, de tokens ou de données personnelles.
  • Respecte les autres participants et accepte les résultats du jeu.

Limites techniques actuelles

Les solutions sont vérifiées côté serveur à l'aide de JavaScript. Cette version est conçue pour des défis simples et ne doit pas être considérée comme un bac à sable sécurisé pour du code non fiable. Le déploiement de production devra isoler l'exécution, limiter le temps et la mémoire, valider les entrées et restreindre les permissions réseau.

Signaler un problème

Si tu découvres une vulnérabilité, ne publie pas de détails exploitables dans une issue publique. Contacte le propriétaire du projet via GitHub avec une description, les étapes de reproduction et l'impact potentiel.
